# Сайт группы ЭПиО 6303

Расписание на неделю и презентации лекций для группы ЭПиО 6303
(1 курс, «Экономика предприятий и организаций», Ташкентский филиал РЭУ им. Г.В. Плеханова).

Сайт состоит из обычных файлов, без сервера и базы данных. Чтобы что-то обновить,
нужно поменять файлы в папке `data/` или положить презентацию в `files/`.
Код трогать не нужно.

---

## Что где лежит

```
data/subjects.json          предметы: название, преподаватель, цвет, иконка
data/lectures.json          список лекций
data/schedule.json          расписание на текущую неделю
data/schedule-archive/      прошлые недели
files/<предмет>/            презентации (.pptx/.ppt) и их PDF-версии
admin.html                  редактор расписания (в меню ссылки нет)
convert.py                  конвертация презентаций в PDF
Конвертировать презентации.bat   то же самое двойным кликом
Открыть сайт локально.bat        посмотреть сайт у себя до публикации
```

Страницы `index.html`, `schedule.html`, `subjects.html`, `search.html`, `viewer.html`
и папку `assets/` менять не нужно.

## Как посмотреть сайт у себя

Дважды кликните **«Открыть сайт локально.bat»**. Откроется браузер с сайтом.
Пока окно с чёрной консолью открыто, сайт работает. Закрыли окно, и сайт остановился.

> Просто открыть `index.html` двойным кликом не получится: браузер не даст странице прочитать данные.
> Поэтому нужен этот `.bat`.

## Как добавить лекцию

**Шаг 1. Положите презентацию в папку предмета.**
Например, лекцию по праву: `files/law/`.

Название папки должно совпадать с `id` предмета из `data/subjects.json`:

| Предмет | Папка |
|---|---|
| Микроэкономика | `files/microeconomics/` |
| Право | `files/law/` |
| Математический анализ | `files/math/` |
| История экономических учений | `files/history-econ/` |
| Институциональная экономика | `files/institutional/` |
| Предпринимательство | `files/entrepreneurship/` |
| Антикоррупционная политика | `files/anticorruption/` |
| Иностранный язык | `files/english/` |
| Физическая культура | `files/pe/` |
| Элективы по физкультуре | `files/pe-electives/` |

Если папки ещё нет, просто создайте её.

Называйте файлы **латиницей, без пробелов**, например `tema-3-rynok.pptx`.
Так ссылки точно работают на всех телефонах.

**Шаг 2. Сделайте PDF.**
Дважды кликните **«Конвертировать презентации.bat»**.
Скрипт найдёт все новые презентации и положит рядом PDF с тем же именем.

**Шаг 3. Впишите лекцию в `data/lectures.json`.**
Скрипт из шага 2 сам покажет готовый блок для каждой новой презентации.
Скопируйте его в список и заполните поля:

```json
{
  "lectures": [
    {
      "subject": "law",
      "topic": 2,
      "title": "Нормы права. Источники права",
      "date": "2026-09-21",
      "file": "files/law/tema-2-normy-i-istochniki-prava.pptx"
    },
    {
      "subject": "law",
      "topic": 3,
      "title": "Название новой темы",
      "date": "2026-09-28",
      "file": "files/law/tema-3-nazvanie.pptx"
    }
  ]
}
```

- `subject` — id предмета (как название папки);
- `topic` — номер темы;
- `title` — название темы;
- `date` — дата лекции в формате `ГГГГ-ММ-ДД`;
- `file` — путь к оригиналу `.pptx` или `.ppt`. PDF сайт найдёт сам: то же имя, но `.pdf`.

**Шаг 4. Опубликуйте** (см. ниже).

Готово: лекция появится в блоке «Новые лекции» на главной, на странице предмета и в поиске.
У каждой лекции две кнопки: «Открыть» (PDF прямо на сайте) и «Скачать .pptx».

### ⚠ Три правила JSON, чтобы ничего не сломалось

1. Блоки в списке разделяются **запятой**, но **после последнего блока запятой нет**.
2. Все тексты — в **прямых двойных кавычках** `"..."`, не в «ёлочках».
3. Числа (`topic`) пишутся без кавычек.

Если ошиблись, сайт не сломается молча: вместо данных он покажет, в каком файле ошибка.
Проверить файл можно на https://jsonlint.com — вставьте текст и нажмите «Validate JSON».

## Как обновить расписание на неделю

1. Откройте **редактор**: `admin.html`.
   - У себя: запустите «Открыть сайт локально.bat», редактор будет по адресу `http://localhost:8000/admin.html`.
   - Или на опубликованном сайте: `https://<ваш-логин>.github.io/<репозиторий>/admin.html`.
2. Нажмите **«Следующая неделя на основе текущей»**. Все пары скопируются с датами на +7 дней.
3. Поменяйте то, что изменилось:
   - ✏️ изменить пару, 🗑 удалить;
   - чтобы добавить пару: выберите день и номер пары (время подставится само), предмет, тип и аудиторию, потом «Добавить пару»;
   - галочка «Выходной» отмечает день без пар.
4. **Сначала сохраните старую неделю в архив**: кнопка «Скачать текущую неделю для архива».
   - Положите скачанный файл (например, `2026-09-28.json`) в папку `data/schedule-archive/`.
   - Откройте `data/schedule-archive/index.json` и допишите дату в список:
     ```json
     {
       "weeks": [
         "2026-09-21",
         "2026-09-28"
       ]
     }
     ```
5. Нажмите **«Скачать schedule.json»** и замените им файл `data/schedule.json`.
   Или «Скопировать JSON», откройте `data/schedule.json` в Блокноте, выделите всё и вставьте.
6. Опубликуйте.

Черновик в редакторе сохраняется сам. Если закрыли вкладку, ничего не пропадёт.

На странице «Расписание» есть переключатель **«Прошлая / Текущая»**.
«Прошлая» — самая свежая неделя из архива. Если в архиве больше одной недели,
рядом появится список «Архив недель».

> Файл `data/schedule-archive/2026-09-21.json` — пример. Его можно удалить,
> только уберите `"2026-09-21"` из `index.json`.

**Если поменялось время звонков**, откройте `assets/admin.js` и поправьте список `PAIRS` в начале файла.

## Как конвертировать презентации

Дважды кликните **«Конвертировать презентации.bat»**. Скрипт:

- находит все `.ppt` и `.pptx` в папке `files/` (во всех подпапках);
- делает PDF только для **новых или изменённых** презентаций, старые не трогает;
- подсказывает, каких презентаций нет в `lectures.json`, и выдаёт готовый блок для копирования.

Пересоздать вообще все PDF:

```bash
python convert.py --all
```

Если пишет «LibreOffice не найден», установите LibreOffice и запустите ещё раз.
Если лекция открыта в PowerPoint, закройте её перед конвертацией.

## Как опубликовать сайт (первый раз)

Сайт будет жить бесплатно на **GitHub Pages**, по адресу вида `https://ваш-логин.github.io/epio-6303/`.

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Установите и откройте **GitHub Desktop**, войдите в свой аккаунт
   (*File → Options → Accounts → Sign in*).
3. *File → Add local repository…* → выберите папку с сайтом.
   GitHub Desktop скажет, что это ещё не репозиторий. Нажмите **«create a repository»**.
   Имя: например `epio-6303`. Нажмите **Create repository**.
4. Нажмите **Publish repository** (сверху).
   **Снимите галочку «Keep this code private»**: для бесплатного GitHub Pages репозиторий должен быть публичным.
   Нажмите **Publish repository**.
5. Откройте репозиторий на сайте github.com (*Repository → View on GitHub*).
6. Там: **Settings → Pages**.
   В разделе *Build and deployment*: Source — **Deploy from a branch**,
   Branch — **main**, папка — **/ (root)**. Нажмите **Save**.
7. Подождите 1–2 минуты и обновите страницу. Сверху появится ссылка на сайт.
   Её и отправляйте одногруппникам.

## Как опубликовать изменения

После любых правок (новая лекция, новое расписание):

1. Откройте **GitHub Desktop**. Слева будет список изменённых файлов.
2. Внизу слева в поле *Summary* коротко напишите, что сделали, например «Лекция по праву, тема 3».
3. Нажмите **Commit to main**.
4. Нажмите **Push origin** (сверху).

Через 1–2 минуты изменения будут на сайте. Если сразу не видно,
обновите страницу. На телефоне: потяните страницу вниз.

**Ограничения GitHub:** один файл — не больше **100 МБ**. Если презентация
тяжелее, сожмите картинки в PowerPoint (*Файл → Сжать рисунки*) или сохраните её заново.

## Вариант: хостинг Beget (вместо GitHub Pages)

Бесплатный тариф: 1 ГБ места, 1 сайт, до 25 000 файлов, без рекламы. Техподдержки на нём нет.

**Первый раз:**
1. Зарегистрируйтесь на https://beget.com/ru/hosting/free и войдите в панель управления.
2. Раздел **«Сайты»**: там уже есть сайт или создайте его. Запомните адрес сайта и имя его папки.
3. Раздел **«FTP»**: посмотрите логин и пароль FTP (или задайте новый пароль).
4. Установите **FileZilla Client** (бесплатно): https://filezilla-project.org/
5. В FileZilla вверху: *Хост* `ftp.<ваш-логин>.beget.tech` (точный адрес указан в разделе «FTP»), логин, пароль. Нажмите **«Быстрое соединение»**.
6. Справа откройте папку сайта, затем `public_html`. Удалите оттуда стандартный `index.php` или `index.html`, если он есть.
7. Слева откройте `D:\сайт`, выделите и перетащите вправо в `public_html`:
   `index.html`, `schedule.html`, `subjects.html`, `search.html`, `viewer.html`, `admin.html`
   и папки `assets`, `data`, `files`.
   Файлы `.bat`, `convert.py`, `tools`, `README.md` на хостинг загружать не нужно.
8. Откройте адрес сайта в браузере.

**Обновления:** перетащите в FileZilla только то, что изменили, и согласитесь на замену файлов:
- новое расписание: `data/schedule.json` (и архив из `data/schedule-archive/`);
- новая лекция: `data/lectures.json` и новые файлы из папки `files/<предмет>/`.

## Как добавить или изменить предмет

Откройте `data/subjects.json` и добавьте блок:

```json
{
  "id": "statistics",
  "name": "Статистика",
  "teacher": "доц. Фамилия И.О.",
  "practice": "преп. Фамилия И.О.",
  "color": "#0d9488",
  "icon": "pie"
}
```

- `id` — латиницей, без пробелов (это же имя папки в `files/`);
- `practice` — необязательно, преподаватель практики;
- `short` — необязательно, короткое название для расписания;
- `color` — цвет предмета. Он одинаковый в расписании, карточках и поиске.
  Хорошо смотрятся: `#2563eb` `#7c3aed` `#ea580c` `#0d9488` `#db2777` `#ca8a04` `#dc2626` `#c026d3` `#16a34a` `#0891b2` `#64748b`;
- `icon` — одна из иконок: `chart`, `scale`, `sigma`, `book`, `landmark`, `briefcase`, `shield`,
  `globe`, `dumbbell`, `trophy`, `users`, `calculator`, `coins`, `laptop`, `pie`, `flask`, `pen`;
- `"hideInSubjects": true` — не показывать на странице «Предметы» (как «Кураторский час»).

## Полезное

- **Проверить блок «Сегодня» на любое время:** допишите к адресу `?now=2026-09-30T11:00`,
  например `index.html?now=2026-09-30T11:00`. Сайт покажет всё так, будто сейчас это время по Ташкенту.
- **Время** на сайте всегда ташкентское, даже если телефон стоит в другом часовом поясе.
- **Тема** (светлая/тёмная) по умолчанию как в системе. Кнопка ☀/☾ вверху переключает её, выбор запоминается.
- Демо-презентации в `files/` (тема 2 по микроэкономике и праву) — заглушки.
  Замените их настоящими файлами с теми же именами или поменяйте пути в `lectures.json`.
